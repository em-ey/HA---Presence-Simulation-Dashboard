## Beschreibung

Diese Karte ist eine native Lovelace-Karte, die die nächsten Aktionen, die aktuell aktiven simulierten Entitäten und die zuletzt ausgeführte Simulationsaktion anzeigt.

## Verwendung

Ersetze `switch.anwesenheitssimulator` durch den Namen deines eigenen Presence-Simulation-Switches, bevor du die Karte zu einem Dashboard hinzufügst.
